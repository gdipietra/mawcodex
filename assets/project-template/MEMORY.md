# Project memory

Durable, project-specific corrections and learned facts belong here. Keep
entries concise, evidenced, and current. Do not store credentials, personal
data, confidential source material, or speculative claims as facts.

Use this form:

```text
[LEARN:category] YYYY-MM-DD — fact or correction.
Evidence: file, command result, source, or decision record.
Scope: where this applies.
Supersedes: earlier entry, if any.
```
