# Quality reports

This directory holds durable workflow records:

- `plans/`: approved and completed implementation plans;
- `specs/`: requirements for ambiguous or high-scope work;
- `decisions/`: consequential research or architecture choices;
- `passports/`: numeric-claim provenance and verification status;
- `audits/`: reproducibility, citation, disclosure, and artifact audits;
- `checkpoints/`: intentional handoff and recovery snapshots;
- `diagnoses/`: root-cause investigations;
- `session_logs/`: concise work-session records;
- `preregistrations/`: design commitments;
- `merges/`: reconciliation records for multi-branch or multi-agent work.

Use the matching file under `templates/` where one exists.
