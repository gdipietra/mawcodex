# MAW visual identity

MAW is an original purple academic-workflow mascot based on Giovanni Di
Pietra's `maw_sketch.png`: one central eye, one enormous grin, and a rounded
amorphous silhouette.

## Assets

| File | Use |
| --- | --- |
| `maw-icon.png` | transparent plugin and composer icon |
| `maw-thumbnail.png` | 16:9 plugin card and release thumbnail |
| `maw-pet.png` | transparent academic Codex-pet illustration |
| `*-source-green.png` | chroma-key generation masters retained for editing |

## Palette

- MAW purple: `#9B4AC3`
- Dark aubergine: `#23072E`
- Lavender: `#C98AF2`
- Warm gold: `#F6BD55`
- Paper cream: `#FFF3D6`

## Provenance

The three finished illustrations were generated with OpenAI's built-in image
generation capability on 2026-07-28. The user's sketch supplied the character
composition; the production prompts explicitly requested original artwork and
excluded reproduction of existing video-game or franchise art.

The transparent icon and pet were generated on a solid green background and
processed with the image-generation skill's chroma-key removal helper. Source
generation files remain in the default Codex generated-images directory as
well as the two retained green masters in this folder.
