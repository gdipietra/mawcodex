Original academic workflow

Pedro H. C. Sant'Anna

MAW Codex is substantially adapted from pedrohcgs/claude-code-my-workflow, created by Pedro H. C. Sant'Anna and distributed under the MIT License.

Pedro's workflow provides the planning and verification process, independent review, reproducibility checks, and workflows for research and teaching. These are his contributions. The conversion overview explains which Codex features now carry them out.

Codex adaptation and native additions

Giovanni Di Pietra

Giovanni Di Pietra adapted the skills and agent roles for Codex. He added a project initializer, opt-in hooks, and automated checks. The conversion records link each adapted component to its source.

He also designed ManageRAW and six skills for managing MAW in an existing project: JAW, CAW, PAW, LAW, UAW, and SAW. They help teams decide where MAW fits, record shared settings, and review updates.

The 52 adapted skills and 18 adapted roles credit the original workflow. The catalog uses “native addition” for components created for MAW Codex. Nothing on this site implies endorsement by Pedro H. C. Sant'Anna or any other credited party.
