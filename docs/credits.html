Codex adaptation and native additions

Adaptation author

Giovanni Di Pietra

Giovanni Di Pietra designed and implemented the Codex-native package architecture, semantic conversion, fixed-source provenance ledgers, portable role layer, safe project initializer, opt-in hook mappings, deterministic validators, public documentation, and original MAW visual identity.

He also designed ManageRAW and the JAW, CAW, PAW, LAW, UAW, and SAW capabilities. These additions solve a distinct problem not present in the fixed upstream system: safely adopting and coordinating MAW across ongoing projects, instruction layers, machines, and specialist plugins without erasing local authority.

“Codex-native adaptation” does not mean the upstream workflow has been renamed away. The 52 source-derived skills and 18 source-derived roles retain upstream lineage. “Native addition” is reserved for components with no upstream counterpart. Nothing on this site implies endorsement by Pedro H. C. Sant'Anna or any other credited party.

Upstream TikZ rules credit MixtapeTools. Because the reviewed root exposed no standalone license file, MAW Codex preserves conceptual credit but replaces the two texts with original geometry-based rules.

The upstream replication protocol credits a Material Passport concept from academic-research-skills, licensed CC BY-NC 4.0. MAW Codex does not copy that text or schema; its narrower numeric claim passport is an original implementation with conceptual credit.

Dhuliawala et al. - Chain-of-Verification

The isolated claim-verification workflow is informed by the 2023 paper Chain-of-Verification Reduces Hallucination in Large Language Models. The research idea is cited; paper text is not redistributed.

stata-mcp

Some Stata workflows can use stata-mcp. It is an optional external dependency and is not bundled, installed, configured, or authorized by MAW Codex.

Visual identity

The purple MAW mascot is an original visual identity based on Giovanni Di Pietra's sketch. Finished assets were produced with OpenAI's image generation capability on July 28, 2026, using prompts that requested original artwork and excluded existing game or franchise art. The brand work is not derived from Pedro's repository.

How to cite

The repository ships CITATION.cff for MAW Codex and includes the upstream software as a related reference. If the original workflow materially shaped your use, cite or acknowledge Pedro's project as well as this adaptation.
