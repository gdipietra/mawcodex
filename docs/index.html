Project management tools

MAW Codex adds six skills to help teams bring the workflow into existing projects and maintain it over time.

ManageRAW

The management agent routes work to the appropriate skill and records shared decisions in the project profile. External actions still require user approval.

JAW · Join

Checks which files are authoritative, what material needs protection, and which dependencies or conflicts could affect adoption. The first pass is read-only.

CAW · Coordinate

Assigns each step to MAW, an existing project workflow, another plugin, or a connector. The user resolves choices that affect how the project is run.

PAW · Personalize

Keeps team choices in .maw/profile.yaml and personal settings in the ignored .maw/local.yaml. Shared safeguards still apply.

LAW · Layer

Sets up root and nested AGENTS.md instructions and checks which rules apply at specific paths.

UAW · Update

Compares the installed MAW base, the project's settings, and a proposed update. The user can review conflicts before applying changes.

SAW · Slice

Summarizes what a project learned for reuse elsewhere. It excludes credentials, private data, student information, and unpublished work.

Evidence and permissions

Report what was checked

PASS requires observed evidence. FAIL means a check failed. UNVERIFIED covers checks that could not run or lacked the evidence for a verdict.

Protect project material

Preserve raw data and check restricted outputs for disclosure before sharing. Get approval for actions such as a push, deployment, or submission.
