Public policy

Privacy

Effective August 22, 2026. MAW Codex is a local workflow package, not a hosted research service.

This page describes the code published in this repository. It does not replace the privacy policies of GitHub, OpenAI, Codex connectors, or any external service a user independently chooses.

The website

The MAW Codex website is a static GitHub Pages site. The repository includes no analytics script, advertising tracker, account system, form processor, application backend, or first-party cookie.

GitHub hosts the site and may process network and access information under its own policies. Consult GitHub's Privacy Statement for hosting-related processing.

The plugin

MAW Codex runs inside the user's Codex environment and does not operate a publisher-hosted backend. The plugin does not independently collect, sell, or transmit research data, prompts, files, credentials, student information, or usage telemetry to Giovanni Di Pietra.

Some skills can use web access, email, calendar, Drive, GitHub, a browser, or other connectors when those capabilities are available in the active Codex session and the requested workflow requires them. Those actions are governed by the user's authorization, Codex policy, and the external service's terms. MAW Codex requires unavailable operations to remain UNVERIFIED and keeps state-changing external actions behind explicit gates.

Local state

Initialized projects may store tracked shared settings in .maw/profile.yaml, ignored personal or machine settings in .maw/local.yaml, and task evidence in project-local quality reports. The repository's templates exclude secrets, private transcript internals, and raw or restricted data from reusable exports.

Support communications

If you open a GitHub issue or security advisory, GitHub processes the information you submit. Do not include confidential data, credentials, student records, unpublished restricted material, or exploitable security details in a public issue.

Changes

Material policy changes will be versioned in this repository. The effective date above identifies this published text.

Contact

Use the support routes. Security-sensitive reports should use a private GitHub security advisory when that feature is available.
